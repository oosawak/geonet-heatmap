# 地殻変動ヒートマップ（試作）

国土地理院の電子基準点（GNSS）の「日々の座標値」から、地面の動き（直近7日間平均と約30日前の7日間平均の差）をヒートマップで見える化する試作です。**地震予測ではありません。**

公開ページ:
- 東北: https://oosawak.github.io/geonet-heatmap/
- 三重・四国とその周辺: https://oosawak.github.io/geonet-heatmap/nankai/

地図の縦横比は、地域の中心緯度のコサインで経度幅を補正した実物の比率に合わせています。地図上の震央（○）と震度観測点（◆）はクリック／タップで詳細が見られます。

## データの正本は Markdown

毎日の計算結果は地域ごとの `snapshots/<最新観測日>.md`（東北）／ `snapshots-nankai/<最新観測日>.md`（三重・四国とその周辺、19県）に Markdown で保存します（メタ情報＋観測点ごとの変位表＋震央リスト＋震度観測点表）。ページはこの Markdown 正本から生成する生成物です。スナップショットが貯まると、ページ上の日付セレクタで過去分に切り替えて見られます。

## 重ね合わせ・参考表示

- **震央**（気象庁）: 対象期間（比較期間の初日〜直近期間の末日）・M3.0以上の地震。抽出範囲は東北が緯度35.5〜42.5／経度138.0〜145.0、三重・四国とその周辺が緯度30.5〜37.35／経度129.8〜140.1。丸の大きさ＝マグニチュード、輪の色＝深さ。
  - 2系統の統合: 正式カタログ（地震月報カタログ編の震源データ＝確定値）がカバーする期間は確定値を正とし、日別の震源リスト（暫定値）は未収録の直近期間を埋める。各地象の由来（確定／暫定）はスナップショットに記録。
  - 正式カタログは刊行が遅れ、現時点では対象期間（2026年9〜10月）分は未刊行のため、現在は全件が暫定値。
- **震度観測点**（気象庁・地震情報JSON）: 対象地域の観測点ごとに期間最大震度（震度3以上）を◆で表示。地震情報JSONの公開範囲（直近約30日）までしか遡れないため、集計期間はスナップショットに明記する。
- **月の満ち欠け／太陽―地球―月の位置／大潮・小潮**（右上）: 天文計算による表示。日付切替に連動。
- **地磁気**: GFZ の Kp 指数（その日の最大値）を右上に小さく表示。
- **Yahoo!天気・災害「地震情報」への外部リンク**ボタン（iframe 埋め込みは Yahoo 側ポリシーで不可のためリンク形式）。

## 毎日更新の手順

前提: 速報解 R5.1 のデータが取得できること（下記「R5.1 の取得について」の制約を参照）。

```bash
cd ~/workspace/geonet-heatmap
python3 scripts/update.py
```

`update.py` が一連で実行します: 取得（R5.1、東北213点）→ 計算（変位＋重ね合わせデータ取得）→ `snapshots/` へ Markdown 正本を保存 → ページ再生成 → commit・push。所要時間の目安は取得込みで約10〜20分（地震・震度・地磁気の取得を含む）。

- R5.1 が規定数（10点）未満しか取得できない場合は、ページを一切変更せず終了コード 2 で止まります（古い解での代用更新を防ぐため）。
- 取得だけ／計算だけを個別に回す場合:
  - 取得: `GEONET_SOL=R5.1 python3 scripts/fetch_shard.py <開始index> <個数>`（並列実行が前提の分割実行用。通常は `update.py` 経由でよい）
  - 計算: `python3 scripts/compute_displacement.py --data-dir data/R5.1 --sol R5.1`
  - ページ生成: `python3 scripts/build_page.py`

## R5.1 の取得について（2026-11-08 時点の制約）

- 最終解 F5.1 は terras.gsi.go.jp の Web 経路（pos_main.php → pos_download.php → unt/file_download.php）で登録なしに取得できた（試作 v1 はこの経路）。
- 速報解 R5.1 は同じ Web 経路では取得できない。座標値ダウンロードページの解セレクトには F5.1／F5 しかなく、`sol=R5.1` を直接 POST しても全観測点で「未登録」が返る（2026-11-08 に複数観測点・複数年で確認）。
- 国土地理院の案内では R5.1 の取得方法は「Web または SFTP」。ファイル置き場型の配布は FTP から SFTP に移行済み（FTP は 2026-10-30 終了）で、**SFTP の利用にはユーザ登録が必要**（terras.gsi.go.jp の ftp_user_regist.php で氏名・メールアドレス・パスワードを登録）。
- したがって毎日更新（R5.1）を実際に回すには、次のどちらかが必要:
  1. 本人が SFTP ユーザ登録を行い、その認証情報で SFTP 取得に切り替える
  2. 本人が取得した .pos ファイルを `data/R5.1/` に渡す運用にする
- R5.1 解そのものは毎朝2日前の分まで公開される（IGS速報暦使用、2025-09-21 以降のデータが対象）。

## 失敗しやすい点

- 取得は **curl** で行うこと（この環境の urllib は GSI サーバーに接続を切られる）。
- terras のステージング済みファイルの GET は断続的に "File does not exist" を返す。**POST+GET を1単位としてリトライ**し、取得ファイル内の観測点ID（`; GNSS Point ID`）が要求と一致するか照合すること（別観測点のファイルが返ることがある）。
- GSI 側で「未登録」の観測点が一定数ある（F5.1 では東北213点中22点）。取得失敗ではなくデータ自体が無い。
- 震度データベース（eqdb）の検索は Web UI 前提でプログラム経路がないため使っていない。震度は地震情報JSON（list.json＋詳細JSON）が正規の経路。ただし遡れるのは直近約30日まで。
- 地震月報カタログ編の震源データ zip の置き場所は `bulletin/data/hypo/hYYYY[MM].zip`。書式説明ページのリンクは古く、実ファイルは年次（hYYYY.zip）が中心で、月次は一部のみ。

## 構成

- `scripts/fetch_shard.py` — GSI Web 経路の取得（解は環境変数 `GEONET_SOL`、年は `GEONET_YEAR`、保存先は F5.1 のみ `data/`、他は `data/<解>/`。地域用に `GEONET_STATIONS`／`GEONET_DATA_DIR`／`GEONET_TAG` で観測点リストと保存先を切り替え可能）
- `scripts/list_stations.py` — 観測点リストの作成（`--region tohoku|nankai`）
- `scripts/compute_displacement.py` — 変位計算＋重ね合わせ取得の統合、Markdown 正本の出力（`--region tohoku|nankai` で対象範囲・震源抽出範囲・震度対象県・保存先を切替）
- `scripts/jma_quakes.py` — 気象庁の震源2系統（カタログ／日別リスト）の取得と統合
- `scripts/jma_intensity.py` — 気象庁・地震情報JSONからの震度観測点の集計
- `scripts/geomag.py` — GFZ Kp 指数の取得
- `scripts/build_page.py` ＋ `scripts/template.html` — Markdown 正本 → ページ生成（両地域分を生成。canvas 寸法は中心緯度のコサイン補正で実物の縦横比に合わせる）
- `scripts/update.py` — 毎日更新の一括実行（現行は東北分のみ）
- `snapshots/` — Markdown 正本（東北）、`snapshots-nankai/` — Markdown 正本（三重・四国とその周辺）
- `data/` — F5.1 の .pos（東北）、`data-nankai/` — F5.1 の .pos（三重・四国とその周辺）、`data/R5.1/` — R5.1 の置き場

## 計算方法と注意

- 変位 = 直近7日間平均 − 約30日前の7日間平均（水平は東西・南北成分から合成、上下は別記）。
- 異常に大きな変位（水平50mm超／上下80mm超）は、アンテナ交換などによる見かけの跳びの疑いとして除外し、スナップショットに記録する。
- 2011年の東北地方太平洋沖地震の余効変動やプレート運動（ITRF基準）を含む動きで、観測誤差は数mm程度。海の部分の色は陸の観測点からの補間の伸びで、海上に観測点はない。

## 出典

- 地殻変動データ: 国土地理院「電子基準点データ提供サービス 日々の座標値」（DOI: 10.57499/GSI_GNSS_2026_001）を加工して作成
- 震源データ: 気象庁（日別の震源リスト＝暫定値、地震月報（カタログ編）震源データ＝確定値）
- 震度データ: 気象庁（地震情報JSON）
- 地磁気: GFZ（ドイツ地球科学研究センター）Kp指数
